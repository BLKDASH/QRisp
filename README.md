# QRisp

适用于 Chrome 和 Edge 的离线二维码生成扩展。

## 安装（无需编译）

1. 解压 ZIP，保留整个 `fangjian_qr` 文件夹，不要只拖入 ZIP。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择含 `manifest.json` 的 `fangjian_qr` 文件夹。
5. 在工具栏的扩展菜单中固定「QRisp」。打开网页后点击图标。

## 功能

- 当前页面：打开弹窗自动读取活动标签页的标题与完整 URL，立即离线生成二维码。
- 在网页上选中文字，右键选择「使用QRisp生成二维码」。扩展会自动弹出工具栏气泡并切换到「自定义内容」展示二维码（在无工具栏窗口中自动回退为独立小窗），可编辑原文、复制二维码图片或下载。
- 在「自定义内容」中输入或修改链接、文字时，二维码预览会自动更新。
- 点击「下载二维码」直接保存 PNG，点击右侧箭头可选 PNG、JPG 或 SVG。输入为空或超出容量时，下载和复制按钮会禁用。
- 「当前页面」可复制链接，「自定义内容」可复制 PNG 二维码图片。复制成功后，按钮变为浅绿色并显示「✓ 已复制」，1.5 秒后恢复。
- 支持中文、Emoji 和换行。所选文字和自定义内容最多支持 1000 个 Unicode 字符，且 UTF-8 编码后不能超过 2330 字节。超限时会提示缩短内容。
- 标签切换支持方向键、Home、End，支持中文输入法组合输入。

## 界面

- 弹窗使用 Google Material 风格的白色背景、浅蓝标签、圆角控件和四色二维码图标。
- 预览和导出使用黑白二维码，保留 4 模块静区。二维码密度随内容变化。

## 隐私与权限

- `activeTab` 用于在用户打开工具栏弹窗时读取当前标签页标题和 URL。
- `contextMenus` 用于添加选中文字时的右键菜单项。只有点击该项，QRisp 才处理浏览器交付的所选文字。扩展无需向网页注入脚本或监听选区变化。
- `clipboardWrite` 用于在点击复制按钮时将链接或二维码图片写入剪贴板。
- 二维码计算、字体、脚本和资源全部离线；无分析、无广告、无外部请求、无远程二维码服务。
- 所选文字经本机内存一次性传给扩展弹窗（无工具栏窗口下传给独立小窗），超时未领取即清除。关闭弹窗后，扩展不保存所选文字或自定义输入。导出的二维码包含所编码的数据，请谨慎分享带有令牌或私密信息的 URL。
